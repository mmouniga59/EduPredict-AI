# EduPredict AI

### Student Academic Performance Prediction Using Machine Learning

EduPredict AI is a machine learning-based web application designed to predict student academic performance using study hours, attendance, previous marks, and assignment marks.

## Features
- Student Performance Prediction
- Machine Learning Integration
- Interactive Dashboard
- Student Academic Analysis
- Performance Evaluation

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Machine Learning
- Scikit-learn
- Pandas

## Project Structure
- `app.py` – Flask web application
- `train_model.py` – Model training
- `predict.py` – Prediction logic
- `student_data.csv` – Dataset
- `model.pkl` – Trained ML model
- `templates/` – HTML pages

## Project Purpose
To help understand and predict student academic performance using machine learning.
