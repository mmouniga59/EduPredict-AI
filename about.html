About EduPredict AI

Learn about the project, its objectives and technologies.

📌 Project Overview

EduPredict AI is a Machine Learning-based web application designed to estimate student academic performance. It uses study hours, attendance, previous marks and assignment marks as input features to predict expected academic marks.

🎯 Project Objective

The main objective is to demonstrate how Machine Learning can analyze academic information and estimate student performance. The system also provides a simple web interface to make predictions easily.

💡 Problem Statement

Understanding academic performance involves considering several factors. This project demonstrates a simple automated approach to estimating expected marks from selected academic details.

💻 Technologies Used

🐍 Python

Used for data processing and prediction logic.

🤖 Scikit-learn

Used to train the Random Forest Regression model.

🌐 Flask

Connects the Machine Learning model with the web application.

🎨 HTML & CSS

Used to build and style the website interface.

📊 Pandas

Used to load and manage the project dataset.

🌲 Random Forest

The regression algorithm used to estimate student marks.

⚠️ Project Limitation

This project uses a small sample synthetic dataset for demonstration and learning purposes. Its predictions are estimates and should not be treated as official academic results. Testing with real, independently collected student data is needed for meaningful evaluation.
