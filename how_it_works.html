How EduPredict AI Works

Understand the process behind student academic performance prediction.

Our Prediction Process

EduPredict AI uses a trained Machine Learning model to estimate student academic marks from four academic inputs.

1

📝 Enter Student Details

The user enters study hours, attendance, previous marks and assignment marks through the website.

2

📊 Process Input Data

Python collects the entered values and prepares them in the required format for the trained model.

3

🤖 Machine Learning Prediction

The trained Random Forest Regression model processes the input values and estimates the student's marks.

4

🎯 Display Prediction Result

The website displays the estimated marks, performance category and a supportive message.
